# Website TJKT (Teknik Jaringan Komputer & Telekomunikasi)

Repositori ini berisi kode sumber untuk landing page resmi **Teknik Jaringan Komputer & Telekomunikasi (TJKT)**. Website ini dirancang modern dan responsif untuk menampilkan informasi profil jurusan, statistik, keunggulan program, hingga pendaftaran siswa baru (PPDB).

---

## Fitur & Struktur Halaman

Berdasarkan navigasi dan antarmuka utama website:

- **Beranda**: Tampilan hero section modern dengan statistik utama jurusan serta tombol *Call to Action* (Explore Program & Join Us).
- **Tentang**: Informasi seputar profil, keunggulan, serta latar belakang jurusan TJKT.
- **Kompetensi**: Ringkasan bidang keahlian dan materi pembelajaran utama.
- **Prestasi**: Catatan pencapaian dan penghargaan yang telah diraih oleh siswa maupun jurusan.
- **Galeri**: Dokumentasi foto kegiatan praktikum, sarana/prasarana, dan lingkungan belajar.
- **Guru**: Profil para tenaga pengajar dan guru produktif TJKT.
- **Kontak**: Informasi alamat dan saluran komunikasi resmi jurusan.
- **Daftar PPDB**: Akses cepat menuju pendaftaran peserta didik baru.
- **Dark Mode Toggle**: Fitur pengubah tema tampilan (*light/dark mode*).
